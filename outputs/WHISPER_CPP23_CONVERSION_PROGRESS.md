The masked softmax mass sums to one within `2.77e-08`, and selected-token probabilities match the Python trace within `0.000109`. Complete greedy and seeded sampled traces both terminate. Temperature plus six named sampling filters reproduce complete 51,864-token probability supports and argmax tokens in all `8` tested distributions, with worst maximum probability error `9.72e-06`. All `7` deterministic sequence-bias, forced-boundary, exponential-decay, repair, and normalization configurations reproduce Transformers token sequences exactly. Contrastive search expands top-k copied K/V branches and transports final decoder hidden states through explicit context-cosine edges; all `6` complete sequences match the source-pinned reference, with worst first-step cosine-penalty error `5.07e-07`. Model applicability is explicit rather than implicit: `5` cases reproduce framework rejection and `7` cases, including non-default BOS values, reproduce pinned model-ignore behavior. Greedy token-byte stop matching reproduces all `7` whole-token, cross-token, final-token-overhang, alternative, and EOS cases. Four additional speech recordings match Transformers exactly at every generated token and in decoded text. One true five-recording Transformers batch also matches a single shared-checkpoint C++23 process item-for-item; the explicit execution policy is sequential with isolated per-item graph and K/V state, not vectorized matrix algebra.
